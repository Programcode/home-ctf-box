# encoding-is-not-encryption

Beginner guided crypto room. Layered base64/hex/rot13 decoding plus
hash identification against a Flask training desk. Points: 75.

- `room.yaml` declares objectives, scope, safety, target, tasks.
- `lesson/` holds the learner-facing brief.
- `target/` builds the training service (Flask, port 8000).
- `solver/solver.py` proves the intended decode path end to end.

Verify locally with `cyberrange solve content/rooms/encoding-is-not-encryption`.
